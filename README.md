An entry for the [make.fun](https://make.fun) competition
**"The One-Line Cat Joke That Lands"** — one joke about cats, a single line,
under 200 characters, and nothing else.

## The joke

> My cat knocked my coffee off the table, watched it spill, then looked at me like I did it — and honestly, with that face, I almost apologized.

## Run it

```sh
python3 main.py
```

The program prints exactly that one line and nothing else.

Why this joke: the cat commits the crime, blames the human with a look,
and the human — knowing full well who did it — nearly apologizes anyway.
That guilty-until-proven-innocent stare is every cat owner's daily life.
